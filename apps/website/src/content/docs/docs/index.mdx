AML is an asynchronous TypeScript and JSX runtime for building executable agent workflows. JSX describes the dependency tree; `AmlRuntime` evaluates it, opens scoped resources, runs provider sessions, and cleans up in reverse order. It is not a UI framework or a second workflow language—ordinary TypeScript still owns control flow and concurrency.

## Install AML

<div class="docs-install-grid">
  <section class="docs-install-panel">
    <p class="docs-install-panel__eyebrow">Application runtime</p>
    <h3>Install the SDK</h3>
    <p>Add the public ESM package to a Node.js 26+ TypeScript project.</p>

```sh
npm install @aml-jsx/sdk
```

    <p class="docs-install-panel__note">Prefer an executable workflow file without application glue? Use the <a href="/docs/cli/">experimental AML CLI</a>.</p>

    <a href="/docs/getting-started/">Configure TSX and run a credential-free workflow →</a>

  </section>

  <section class="docs-install-panel docs-install-panel--agent">
    <p class="docs-install-panel__eyebrow">Coding agents</p>
    <h3>Install the AML authoring skill</h3>
    <p>Give a compatible coding agent the repository-backed AML API, composition, provider, and security guidance.</p>

```sh
npx skills add \
  we-are-singular/aml \
  --skill aml-jsx
```

    <p class="docs-install-panel__note">The skill guides the agent; your project still needs the SDK and its selected provider executables.</p>

    <a href="/docs/agent-skill/">Install, verify, and use the skill →</a>

  </section>
</div>
