Agent Markup Language (AML) is a TypeScript framework for building AI agents and multi-agent applications. Use JSX to compose each agent's instructions, tools, input, and execution environment. AML runs that composition, passes results between agents, and manages session and resource cleanup.

The built-in providers connect to existing coding agents: Codex, GitHub Copilot, GLM, OpenCode, and Pi. Those agents keep their native model loops and tools. Your application owns the workflow around them, including validation, routing, concurrency, and persistence.

## What will you build?

| Start with…                                                    | Learn how to…                                                                   |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| [Your first workflow](/docs/getting-started/)                  | Run an Agent, compose specialists, and connect a live provider.                 |
| [An agent with an application Tool](/docs/cookbook/tools/)     | Grant a typed function to one agent and verify that it is called.               |
| [A code-review workflow](/docs/cookbook/code-review-workflow/) | Gather evidence, run specialists in parallel, and validate their findings.      |
| [A support router](/docs/cookbook/structured-routing/)         | Turn a typed result into an application-authorized decision.                    |
| [A workflow test](/docs/cookbook/testing/)                     | Run the same composition with deterministic providers and inspect its behavior. |

You can start with a single `<Agent />`. Add tools, sandboxes, and workspaces when the task needs them. JSX describes the composition; ordinary TypeScript still handles conditions, loops, and application logic. React is not required.

## Install AML

  <section class="docs-install-panel">
    <p class="docs-install-panel__eyebrow">Application runtime</p>
    <h3>Install the SDK</h3>
    <p>Add the public ESM package to a Node.js 26+ TypeScript project.</p>

```sh
npm install @aml-jsx/sdk
```

    <p class="docs-install-panel__note">Prefer an executable workflow file without application glue? Use the <a href="/docs/cli/">experimental AML CLI</a>.</p>

    <a href="/docs/getting-started/">Configure TSX and run a credential-free workflow →</a>

  </section>

  <section class="docs-install-panel docs-install-panel--agent">
    <p class="docs-install-panel__eyebrow">Coding agents</p>
    <h3>Install the AML authoring skill</h3>
    <p>Give a compatible coding agent the repository-backed AML API, composition, provider, and security guidance.</p>

```sh
npx skills add \
  we-are-singular/aml \
  --skill aml-jsx
```

    <p class="docs-install-panel__note">The skill guides the agent; your project still needs the SDK and its selected provider executables.</p>

    <a href="/docs/agent-skill/">Install, verify, and use the skill →</a>

  </section>
