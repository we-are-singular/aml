## How entries are maintained

AML authors its own changelog. The workflow gathers the authoritative commits with [`<Script />`](/docs/reference/primitives/script/), asks one [`<Agent />`](/docs/reference/primitives/agent/) to investigate the changes, and gives that structured analysis to a second [`<Agent />`](/docs/reference/primitives/agent/) for the reader-facing summary. Deterministic TypeScript validates the result and owns the final document update.
