## How entries are maintained

AML authors its own changelog with two repository-aware [`<Agent />`](/docs/reference/primitives/agent/) trees. The first runs the authoritative commit collector, investigates the changes, and returns a typed draft. The second publishes that draft, then uses a [`<FollowUp />`](/docs/reference/primitives/follow-up/) to review, correct, and format the entry.

The Docker image page is rendered directly from the image package's `CHANGELOG.md`, so an image release updates one
history rather than copying entries into the website.
