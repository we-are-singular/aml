---
title: "<Skill />"
description: "Add reusable inline or local-file instructions at an authored position in an <Agent /> prompt or <System /> block."
---

`<Skill />` resolves reusable instruction text. It may contain inline AML content, read a local text file through `src`, or combine both.

```tsx
import { Agent, AmlRuntime, Skill } from "@aml-jsx/sdk"
import { DeterministicAgentProvider } from "@aml-jsx/sdk/testing"

const runtime = new AmlRuntime({
  agentProvider: new DeterministicAgentProvider(),
})

await runtime.evaluate(
  <Agent>
    <Skill name="House style" description="Editorial rules for release notes">
      Prefer concrete examples and short sections.
    </Skill>
    Rewrite the release note.
  </Agent>
)
```

When both forms are present, file content comes first, followed by a newline and resolved inline content. Optional metadata is prepended as `Skill:` and `Description:` labels.

To load a local instruction file, set the runtime `cwd` deliberately and use the `src` form:

```tsx
const runtime = new AmlRuntime({ cwd: import.meta.dirname, agentProvider })

await runtime.evaluate(
  <Agent>
    <Skill src="./skills/editorial.md" />
    Rewrite the release note.
  </Agent>
)
```

## Props

| Prop          | Type            | Default | Meaning                                          |
| ------------- | --------------- | ------- | ------------------------------------------------ |
| `src`         | `string`        | none    | Local text path resolved from the runtime `cwd`. |
| `children`    | `AmlRenderable` | none    | Inline instruction content.                      |
| `name`        | `string`        | none    | Normalized model-facing label.                   |
| `description` | `string`        | none    | Normalized model-facing description.             |

At least one of `src` or `children` is required, and the combined content must be non-empty.

## Placement and file access

`<Skill />` produces ordinary text at its authored position. Put it inside [`<Agent />`](/docs/reference/primitives/agent/) for prompt instructions or inside [`<System />`](/docs/reference/primitives/system/) for system instructions. A Skill file is read by the AML application process; it is not loaded from [`<Workspace />`](/docs/reference/primitives/workspace/) or [`<Sandbox />`](/docs/reference/primitives/sandbox/) unless the configured runtime cwd points there.

This primitive is distinct from the installable [AML coding-agent skill](/docs/agent-skill/): `<Skill />` contributes workflow instructions at runtime, while the coding-agent skill teaches an external coding agent how to author AML.
